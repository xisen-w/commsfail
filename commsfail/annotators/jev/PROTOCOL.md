# Jev annotation protocol 0.1.0

Frozen before the first live call. This is an exploratory pure-Jev method, not a
claim of equivalence to the standard generative incident annotator.

- Model: `typesafe/jev-1.13`, OpenRouter Decisions API, provider TypeSafe. Accept
  only this release or a dated snapshot of this release. Save the served model.
  No routing to another model, generative explanations, temperature, or effort flag.
- Population: the complete research main-experiment records selected by
  `research__*__n[234]__r1`; n=1 remains outside annotation. Keep input immutable.
- Taxonomy: load the six ordered state_gap failure classes and their 37 patterns
  from the repository catalog. Exclude overhead and out-of-scope patterns.
- Unit: a focal agent post and a failure class. Every agent post is checked against
  all six classes. At most one pattern per class per post. Apply the first-failed-link
  rule to each event; distinct events at a post may have different classes.
- Candidates are enumerated from every agent post, not generated by another model.
  A and B make separate calls on identical selected evidence, with reversed option
  presentation in B. These are same-model replicates, not independent expertise.
- Use the standard E3 bundle. It already abbreviates actions and workspace content.
  Add deterministic lexical retrieval: focal post and acting turn priority, whole
  2.2KB evidence chunks, 17KB state ceiling and 30KB total request ceiling. Task and
  focal post are mandatory. Save block references, hashes, selected context, omission
  counts, and full-board coverage. Refuse oversized mandatory context rather than
  silently truncating. This does not establish exhaustive cross-window recall.
- Each class chooses a catalog pattern, no failure, or undecidable. Use the model's
  typed choice directly; do not threshold confidence as if it were calibrated accuracy.
  Unsaid needs full-board coverage and explicit agent-log evidence. Unreceived needs
  an earlier post from another agent beyond the recorded received prefix.
- Judge independently rechecks all six classes, including missed candidates. A second
  typed call verifies support and selects an actual evidence block, severity 1-5 or
  unknown, repair state, source, and an unseen post where required. Failed evidence
  checks are retained as rejected/uncertain, not silently made into incidents.
- Keep anchors separate. Do not imply that adjacent anchors have been merged into
  unique multi-post incidents. Report A/B agreement on fixed post/class slots; retain
  unknowns and disclose same-model dependence. Do not call it standard incident F1.
- Freeze `final.json` before grade attribution. Then, for every lost rubric item,
  Jev selects a primary cause and optionally a retained incident. Unknown is allowed.
  Grade attribution is a structured judgment, not proof of causation. No model-written
  explanation exists; output explanation fields are null rather than invented prose.
- Technical retries: up to 3 retries for transient transport/HTTP errors. Model/provider
  mismatch, invalid distributions, and incompatible input fail closed. All raw responses
  and attempts are retained. Cache validated responses by stage and exact request.
  Explicit resume can make another bounded attempt set after exhaustion.
- Pin protocol/code/input hashes in output configuration. Any change needs a new output
  root. Completed runs need artifact hashes, complete sweeps and valid grade coverage.
- Validation sequence: offline tests; synthetic positive/negative transport controls;
  two complete research cases; then the 30-case batch. Keep pilot and production roots
  separate. Pilot is a technical check, not a labeled accuracy evaluation. No threshold
  tuning or comparative outcome analysis during production.
- Preserve prompts, responses, probability vectors, selected evidence, omissions, usage,
  failures and rejections. API keys are never written to artifacts. Output is private
  to the running user by default. Research records remain outside the source repository.

Known limits: post-based candidate generation misses failures with no suitable post;
multiple same-class events at one post collapse to one choice; bounded retrieval can
miss remote evidence; explanations and free-form causal narratives are unavailable;
same-model agreement and structural validity do not establish labeling accuracy.
